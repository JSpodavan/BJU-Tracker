# Сайт для планирования питания

Веб-приложение для отслеживания питания, поиска продуктов, создания блюд и планирования рациона на неделю.

## 🛠 Технологии

- **Backend:** Node.js, Express.js
- **Database:** PostgreSQL
- **Authentication:** JWT (в httpOnly cookie), bcryptjs
- **Email:** Nodemailer (Gmail)
- **Frontend:** HTML, CSS, JavaScript (чистый)
- **Charts:** Chart.js
- **Icons:** Font Awesome
- **Внешние API:** Edamam (БЖУ продуктов), OpenFoodFacts (категории), MyMemory (перевод русских запросов на английский)

## ✨ Возможности

- 🔐 Регистрация с подтверждением почты и вход
- 🔑 Восстановление и смена пароля по ссылке из письма
- 🔍 Поиск продуктов с информацией о БЖУ (можно вводить на русском)
- ⭐ Добавление продуктов в избранное
- 🍳 Создание блюд из избранных продуктов
- 📅 Планирование питания на неделю
- 📊 Отслеживание активности и статистики
- 🏆 Система достижений

## 📋 Требования

- Node.js 18+
- PostgreSQL 12+
- Gmail-аккаунт с паролем приложения (для отправки писем)
- Ключи Edamam Food Database API

## 🚀 Установка и запуск

### 1. Клонируйте репозиторий
```bash
git clone https://github.com/JSpodavan/BJU-Tracker.git
cd BJU-Tracker
```

### 2. Установите зависимости
```bash
npm install
```

### 3. Создайте базу данных

Таблицы автоматически не создаются — их нужно создать один раз вручную.
Схема лежит в файле [`database.sql`](database.sql).

**Вариант А — через командную строку (psql):**

```bash
cp .env.example .env
```

Отредактируйте `.env`:
```env
# Server
PORT=5000

# PostgreSQL
PG_HOST=localhost
PG_PORT=5432
PG_USER=postgres
PG_PASSWORD=ваш_пароль
PG_DATABASE=название_бд

# JWT
JWT_SECRET=любой_секретный_ключ

# Edamam API (https://developer.edamam.com/)
EDAMAM_ID=ваш_app_id
EDAMAM_KEY=ваш_app_key

# Email для восстановления пароля
EMAIL=ваш_email@gmail.com
EMAIL_PASS=пароль_приложения_google
```

### 4. Настройте базу данных

Создайте пустую базу данных в PostgreSQL:
```sql
CREATE DATABASE your_database_name;
```

### 5. Запустите сервер
```bash
node server.js
```

### 6. Откройте в браузере
```
http://localhost:5000
```
(если в `.env` указан другой `PORT` — используйте его)

## 👤 Работа с аккаунтом

- **Регистрация.** После регистрации на почту приходит письмо со ссылкой подтверждения (действует 1 день). Войти можно только после подтверждения почты. Если ссылка устарела — на открывшейся странице можно запросить новое письмо; если письмо не пришло — зарегистрируйтесь с той же почтой ещё раз, придёт новое.
- **Требования к паролю** (при регистрации и при смене пароля):
  - не менее 8 символов;
  - хотя бы одна цифра;
  - хотя бы один специальный символ: `! @ # $ % ^ & *`.
- **Сброс пароля.** «Восстановить пароль» на странице входа или «Сменить пароль» в профиле — на почту придёт ссылка (действует 1 час).

## 🔧 API Endpoints

### Авторизация
- `POST /user` — Регистрация (отправляет письмо подтверждения)
- `GET /user/verify-email?token=...` — Подтверждение почты по ссылке из письма
- `POST /user/resend-verification` — Повторная отправка письма подтверждения
- `POST /user/login` — Вход
- `GET /user/auth` — Проверка токена
- `POST /user/logout` — Выход
- `POST /user/send-reset-email` — Отправка письма для сброса пароля
- `POST /user/switch-password` — Установка нового пароля по токену из письма

### Профиль
- `GET /api/getUserProfile` — Получить «О себе»
- `POST /api/updateAbout` — Изменить «О себе»
- `GET /api/activity` — Статистика активности

### Продукты и блюда
- `POST /api/search` — Поиск продукта
- `GET /api/loadHistory` — 6 последних найденных продуктов
- `POST /api/favourite` — Добавить в избранное
- `GET /api/loadFavourite` — Получить избранное
- `DELETE /api/deleteFavourite` — Удалить из избранного
- `POST /api/createDish` — Создать блюдо
- `GET /api/DishList/:id?week=...` — Список блюд, план и итоги БЖУ за неделю
- `DELETE /api/deleteDish` — Удалить блюдо
- `POST /api/createMeal` — Добавить блюдо в план питания

Все запросы `/api/*` требуют авторизации (cookie `auth_token`) и работают только с данными текущего пользователя.
